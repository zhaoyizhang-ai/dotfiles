# Evaluation Prompt: Feasibility Check

## Objective
Assess the practical feasibility of an idea cluster by gathering supporting evidence, identifying technical dependencies, and estimating implementation complexity.

## Cluster Information
- **Cluster ID**: [Populate per cluster]
- **Core Idea**: [One-sentence description]
- **Keywords**: [3-5 search terms derived from the idea]

## Research Questions
1. Is there theoretical or empirical evidence that this approach can work?
2. What are the key technical dependencies, and how mature are they?
3. What resources (compute, data, expertise) would implementation require?
4. Have similar approaches been successfully implemented at comparable scale?

## Search Strategy
- Search for empirical validations of the underlying mechanism
- Search for technical maturity assessments of key dependencies
- Search for implementation case studies in related areas
- Check for available tools, frameworks, or libraries that support the approach

## Expected Output
- Feasibility rating: high / medium / low / uncertain
- Supporting evidence summary (with citations)
- Key dependency maturity assessment table:

| Dependency | Maturity | Risk Level | Notes |
|---|---|---|---|

- Implementation complexity estimate: low / medium / high
- Critical path identification: what must be proven first?
