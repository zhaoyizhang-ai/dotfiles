# 中文 AI 痕迹检测与降重

检测中文学术文本中的 AI 写作痕迹，按严重程度分级，给出具体替换方案。

## 使用方式

用户说"检查这篇论文的 AI 痕迹""帮我去 AI 化""降重"时自动触发。

## 检测流程

### 第一步：扫描标记

逐段扫描，对每段标记 AI 痕迹类型和严重程度。

### 第二步：分级报告

按三级输出：
- **高危**（必须改）：绝对断言、空洞形容词、模板开头、捏造数据
- **中危**（应该改）：无过渡段落、成套序数词、模糊量词
- **低危**（可选改）：句式单一、修饰语过多

### 第三步：给出替换

每条标记给出具体的替换文本，不是笼统建议。

## 中文 AI 高频模式库

### 一、高危模式

| 模式 | AI 示例 | 人的写法 |
|------|---------|----------|
| 模板开头 | 近年来，随着……的飞速发展 | 直接进入问题：2024年全球研发排名前50的企业中…… |
| | 在……背景下 | 删掉，从具体事实开始 |
| | 随着全球化进程的不断深入 | 删掉整句 |
| 绝对断言 | 显而易见、毋庸置疑、必然 | 从……的案例来看／实验数据显示 |
|  | 这充分说明、充分体现 | 这说明／这表明（去掉充分） |
| 空洞修饰 | 显著提升、大幅改善 | 替换为具体数据，如"从12%提升到34%" |
|  | 具有重要的理论意义和实践价值 | 删除，或者具体说明是什么意义 |
|  | 做出了重要贡献 | 具体说明做了什么 |
| 捏造引用 | [1]-[5]堆叠引用 | 每篇单独讨论做了什么 |

### 二、中危模式

| 模式 | AI 示例 | 人的写法 |
|------|---------|----------|
| 成套序数 | 首先……其次……再次……最后…… | 分散到不同段落，用自然过渡 |
| 模糊量词 | 大量研究、许多学者、近年来 | 三项研究／张三等人／2019至2023年间 |
| 段落无桥 | 直接跳到下一话题 | 加过渡句：这个问题的另一面是……／与……不同的是…… |
| 段尾空话 | 从而推动了……的进一步发展 | 删掉，或者落回到具体判断 |
| 填充连接 | 值得注意的是、不可否认的是、总而言之 | 删掉，直接说 |
|  | 与此同时、此外、另一方面 | 分散使用，不要一段内出现三个以上 |

### 三、低危模式

| 模式 | 说明 |
|------|------|
| 句长均等 | 每句40-60字像机器。混入短句（8-15字）打断节奏 |
| 修饰语堆叠 | 三个以上"的"连用。拆成两句话 |
| 引号冒号分号泛滥 | AI 喜欢用引号包装术语、用分号串并列、用冒号起解释。尽可能替换为逗号和句号 |

### 四、中文特有的 AI 痕迹

**连接词密度过高**：AI 倾向在句首大量使用"因此""所以""然而""此外""与此相对""在此基础上"。正常中文写作的连接词密度约为每300字1个，AI 写作可达每100字1个。

**主语重复**：AI 习惯每句带完整主语（"本文""该研究""这一发现""中国"），人的写作省略主语更频繁。

**成语和四字格过密**：AI 喜欢"举足轻重""不可或缺""日新月异""突飞猛进"，正常学术写作中这些词汇密度极低。

**"的"字密度**：AI 文本"的"字占比通常高于6%，正常学术中文约为4-5%。

## 操作策略

### 降 AI 率最有效的 5 个方法（按效果排序）

1. **每一段尾句换成具体判断**。AI 的段尾是"这推动了……的发展"，人的段尾是"苏联体制中的企业从来没有面对过这种压力，自然也从未生长出这种能力。"

2. **加过渡句而不是序数词**。不是"第一第二第三"，而是"与企业的转制几乎同步，高校也……""上述变化的合力催生了……"

3. **删掉所有模板开头**。以"2024年""1978年9月""1947年美国贝尔实验室"这类具体时间地点人物开头，不要"在……的背景下""随着……的发展"。

4. **短句打断长句节奏**。每200-300字插入一句15字以下的判断句：事实很清楚。结果不是这样。这正是问题所在。

5. **引注逼实**。每出现一个论断就放一个引注编号，既降 AI 率又合学术规范。

### 不适合作为通用策略的（容易翻车）

- **用"笔者"**：是否适合取决于导师偏好和学科惯例。有些导师认为用"笔者"是好事（区别于 AI），有些认为大三课程论文避免使用更稳妥，应依据具体场景判断
- **刻意口语化**：与学术写作规范冲突
- **故意打乱逻辑顺序**：牺牲论文质量换低 AI 率，得不偿失
