# Evaluation Prompt: Prior Art Check

## Objective
Assess the novelty of an idea cluster by searching for existing implementations, related approaches, and prior research.

## Cluster Information
- **Cluster ID**: [Populate per cluster]
- **Core Idea**: [One-sentence description]
- **Keywords**: [3-5 search terms derived from the idea]

## Research Questions
1. Has this idea (or a closely related variant) been implemented before?
2. What are the most similar existing approaches in the same domain?
3. Are there structurally similar approaches in adjacent domains?
4. What is the closest prior art, and how does this idea differ?

## Search Strategy
- Exact match: Search for direct implementations using cluster keywords
- Near match: Search for approaches with similar mechanisms but different framing
- Cross-domain: Search for analogous solutions in related fields
- Sources: Academic papers, technical blogs, patents, industry reports

## Expected Output
- Novelty rating on 4-level scale (★★★★ Novel / ★★★☆ Mostly novel / ★★☆☆ Partially novel / ★☆☆☆ Well-explored)
- Top 3 most related prior works with title, relevance score (1-5), and key differentiators
- Clear statement of how the idea differs from closest prior art
- Recommendation: proceed / pivot / deprioritize
