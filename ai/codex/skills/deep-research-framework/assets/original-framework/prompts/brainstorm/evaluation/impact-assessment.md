# Evaluation Prompt: Impact Assessment

## Objective
Evaluate the potential impact of an idea cluster against user-defined value criteria, considering both upside potential and scope of applicability.

## Cluster Information
- **Cluster ID**: [Populate per cluster]
- **Core Idea**: [One-sentence description]

## Evaluation Dimensions
[Populate from `context/from-human/brainstorm-context.md` — user-defined criteria]

## Assessment Questions
1. If successfully implemented, what is the magnitude of improvement over existing approaches?
2. How broad is the applicability — does this solve a narrow or wide class of problems?
3. What is the time-to-impact — how quickly could value be realized?
4. Does this create compounding advantages or one-time gains?
5. How does this compare to other clusters in the pool on each value dimension?

## Expected Output
- Impact rating: transformative / significant / moderate / incremental
- Per-dimension scoring (1-5) with justification:

| Dimension | Score | Justification |
|---|---|---|

- Best-case and worst-case impact scenarios
- Comparative ranking notes vs. other clusters
